# Horror bookstore storefront

Plan a Next.js and TypeScript storefront for a specialist horror bookseller. This repository owns the shopping and staff interfaces and consumes the backend's versioned OpenAPI contract.

## First storefront milestone

Build a mobile reading path from a curated shelf to a specific edition. Start with one title offered in paperback and hardcover so the design can demonstrate different prices and stock states.

- **Home and browse.** Feature a bookseller's pick and shelves for folk, cosmic and gothic horror. Let readers search by title or author and filter by subgenre, format and availability.
- **Book detail.** Put the cover, title and author first, followed by the edition selector, price, availability and purchase action. Add a synopsis and a bookseller's note.
- **Cart and payment.** Preserve the reader's selections when inventory changes. Explain which edition sold out and let them adjust the order. Display confirmation from the backend's order status.
- **Design.** Use charcoal, warm ivory and oxblood with Spectral titles and Inter controls. Test readable contrast, visible focus, keyboard navigation and reduced-motion preferences.

The backend repository holds the full build sequence, inventory rules and integration milestones. With the repositories checked out side by side, the plan is at `../horror-bookstore-backend/BOOKSTORE_PLAN.md`.
